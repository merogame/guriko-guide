# グリコガイド

[ガイドを開く](https://merogame.github.io/guriko-guide/)

二人対戦のグリコゲームで、残り歩数に応じた均衡戦略から自分の手を抽選するガイドです。画面上部に相手・自分の残り歩数、中央に推奨手、下部に相手の手を入力する3ボタンだけを表示します。

## 使い方

1. ゴールまでの歩数を設定して「開始」を押します。初期値は30歩、設定範囲は1〜999歩です。
2. 中央に表示された手を出し、相手が出した手のボタンを押します。
3. 残り歩数を更新し、「自分＋3」「相手＋6」「あいこ」などの結果を表示します。結果の表示中は3ボタンが無効になります。
4. 中央の結果をタップすると、次の推奨手を抽選します。
5. ゴールすると「勝ち」「負け」を表示します。中央をタップすると歩数の設定に戻ります。

同じ手番の推奨手は固定されます。次も同じ手が表示されることがあります。再読み込みすると歩数の設定に戻ります。結果はキーボードのEnter・スペースでも進められます。

## ルール

二人が同時にじゃんけんをし、勝った人だけが次の歩数を進みます。

| 勝った手 | 進む歩数 |
|---|---:|
| グー | 3 |
| チョキ | 6 |
| パー | 6 |

あいこでは進みません。先にゴールに到達するか、ゴールを越えた人が勝ちです。残り歩数は0未満にはなりません。

## 均衡と精度

対戦全体で先にゴールする確率を基準に、自分と相手の残り歩数ごとの均衡戦略を数値計算します。相手がその確率を知り、最善の対処をする場合を基準にしています。相手の履歴を使った予測は行いません。

進む歩数が3・6・6なので、残り歩数を3で割って切り上げた単位にまとめられます。30歩では継続中の局面は100通りです。勝敗が決まる局面から順に計算し、あいこで同じ局面に戻る効果も含めます。各局面で48回の二分法を使い、値と確率を64ビット浮動小数点で保持します。

開始時に必要な均衡表を計算してページ内に保持し、手を入力した後は表から抽選します。同じ単位数の表は次の対戦でも再利用します。表をダウンロードする通信はありません。抽選には `crypto.getRandomValues` を使います。

保存した確率と32ビット乱数による抽選に対する最適な対処を、1〜999歩で使う全110,889局面について検証しています。

- 30歩の初期状態での最悪勝率：約49.999999966%。
- 全局面での、理論値からの最大勝率低下：約0.000000193ポイント。

浮動小数点による数値検証の結果です。

## 構成

- `index.html`：公開ページ。
- `グリコガイド.html`：保存用。`index.html` と同じ内容です。
- `README.md`：この説明。
- `.nojekyll`：静的ファイルをそのまま配信する設定。
- `tools/verify-equilibrium.mjs`：均衡と抽選精度の検証。
- `tools/accuracy.json`：検証結果。

HTMLファイルを保存すれば、直接ブラウザで開いて使えます。外部ライブラリ、外部フォント、画像、サーバー処理、追加通信は使いません。入力した手や歩数を保存・送信する処理もありません。

ページ内のピンチ、ダブルタップ、ホイール、拡大ショートカットは抑止しています。ブラウザ自身の設定やアクセシビリティ機能による拡大は、ページから完全には禁止できません。

検証はNode.jsで `node tools/verify-equilibrium.mjs` を実行すると再現できます。
